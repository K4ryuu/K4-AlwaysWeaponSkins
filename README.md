## About The Project

This plugin enhances weapon skin visibility by ensuring your equipped Steam inventory skins are displayed consistently across both teams. This means you'll see your custom skins regardless of which team you're on - for example, your Glock skin will be visible even when playing as CT. This feature is particularly valuable in game modes like DeathMatch where players frequently use weapons from both teams.

### Important Notice

Your server may produce some console messages related to pending team changes due to how this plugin functions.
If these messages become bothersome, you have two options to suppress them:

1. Add `ChangeBasePlayerTeamAndPendingTeam` to your console filter by:

- Using [CS2-Egg](https://github.com/K4ryuu/CS2-Egg) as your server egg
- Adding the message to the console filter list

2. Install [CleanerCS2](https://github.com/Source2ZE/CleanerCS2) plugin and:

- Add `ChangeBasePlayerTeamAndPendingTeam` to its block list
- Configure the extension to filter these messages

These solutions will help keep your server console clean while maintaining full plugin functionality.

### Dependencies

To use this server addon, you'll need the following dependencies installed:

- [**CounterStrikeSharp**](https://github.com/roflmuffin/CounterStrikeSharp/releases): CounterStrikeSharp allows you to write server plugins in C# for Counter-Strike 2/Source2/CS2.
